## 6. gRPC Service Implementation

### 6.1 File: `infrastructure/grpc/ProductSkuGrpcService.java`

**Path:** `product-service/src/main/java/com/platform/productservice/infrastructure/grpc/ProductSkuGrpcService.java`

- [ ] Create `@GrpcService` class extending generated `ProductSkuServiceGrpc.ProductSkuServiceImplBase`
- [ ] Inject: `SkuCacheRepository`, `SkuRepository`, `ProductRepository`, `SkuJpaMapper`, `GrpcProtoMapper`, `RedisKeyBuilder`, `DistributedLockRepository`
- [ ] Implement `GetProductSku`:
  - Step 1: `Redis JSON.GET product:sku:{skuId}`
  - Step 2: PER (Probabilistic Early Expiration): if TTL < 5%, query DB and overwrite cache
  - Step 3: Cache miss: acquire distributed lock, query DB, `JSON.SET` with TTL 3600s, release lock
  - Step 4: Return `ProductSkuResponse`
  - Step 5: On error, return empty response with `NOT_FOUND` status
- [ ] Implement `GetBatchProductSkus`:
  - Step 1: `Redis JSON.MGET` all keys in single round-trip
  - Step 2: Identify `missedSkus` (cache misses + stale entries)
  - Step 3: If `missedSkus` not empty: batch query DB, warm cache with pipelining
  - Step 4: Build response from cache + DB results
  - Step 5: Return `BatchProductSkuResponse`
- [ ] Implement `GetCategoryTree`:
  - Call `CategoryService.findTree()`
  - Map to protobuf response
- [ ] Add `@GrpcInterceptor` for logging interceptor
- [ ] Implement retry with Resilience4j circuit breaker
