# Login role of each service on the shared PostgreSQL (security review 2026-10-22, H3; mesh ADR-004).
# One line per database: <database> <role> <environment variable holding the password>.
# service-roles.sh makes the role the owner of the database and of every object in it, revokes
# CONNECT from PUBLIC, and leaves the superuser `postgres` to infrastructure only (Debezium,
# Temporal, postgres-exporter, migrations run by hand, local tools on :15432).
